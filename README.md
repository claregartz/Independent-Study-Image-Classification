# Independent-Study-Image-Classification
These are the files that correlate with my first semester Independent Study, "Building Models for Image Classification." The entire project is described in main.pdf, train.csv is the dataset, and the rest of the files are different models I created. 

To run the notebooks you need to install numpy, pandas, sklearn, pytorch and matplotlib. I used pip to install all of them, e.g. 

> pip3 install torch torchvision torchaudio

for pytorch for example.
